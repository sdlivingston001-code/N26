## <span id="movement-actions">Movement Actions</span>

<span id="movement-actions-move">**Move:**</span> (Single) Move up to **M"**.

<span id="movement-actions-dash">**Dash:**</span> (Double) Move up to **M + I"**.

<span id="movement-actions-engage">**Engage:**</span> (Single) Move up to D6" towards an enemy. If it ends Engaged (Fighters) / within 1" (Vehicles), make a free Fight or Coup de Grace action respectively.

<span id="movement-actions-charge">**Charge:**</span> (Double) Move up to M + D6" towards an enemy. If it ends Engaged / within 1", make a free Fight or Coup de Grace action respectively. Grants +1 Attack and +2 Initiative. Vehicles may only make one turn of ≤90° during a Charge.

## <span id="movement-rules">Movement Rules</span>

<span id="movement-rules-1-inch">**1" Rule:**</span> Can only move within 1" of an enemy model during Charge, Engage, Retreat, and Crawl actions; when Charging/Engaging, this is only allowed if the action ends in base contact. Models can never move through other models.

<span id="movement-rules-vehicles-scenery">**Vehicles as Scenery:**</span> Fighters may move over a Vehicle as if it were scenery. If the Vehicle then moves and the Fighter is not in a designated transport area, the Fighter must pass an Agility test or be placed 1" away in a direction chosen by scatter die.

<span id="movement-rules-climbing">**Climbing:**</span> costs 2" of movement per 1" climbed (Fighters); move normally on ladders and stairs.

<span id="movement-rules-difficult-terrain">**Difficult Terrain:**</span> costs 2" of movement per 1" moved for Fighters; effect on Vehicles depends on terrain type.

<span id="movement-rules-dangerous-terrain">**Dangerous Terrain:**</span> counts as Difficult Terrain, and roll a D6 — on a 1, suffer an automatic Lethality 1 wound with no saves allowed.

<span id="movement-rules-obstacles">**Obstacles:**</span> up to 2" high.

<span id="movement-rules-structures">**Structures:**</span> 2" or higher; must be climbed.

<span id="movement-rules-doors">**Doors:**</span> spend 2" of movement to open/close, or an Interact action to lock/unlock.

<span id="movement-rules-leaping-gaps">**Leaping Gaps:**</span> automatic if less than 2"; an Agility test is required if 2" or more — if failed, the model falls.

<span id="movement-rules-ledges">**Ledges:**</span> Agility test required, or the model falls. Railings give +1 to this test.

<span id="movement-rules-jumping-down">**Jumping Down:**</span> Agility test; if passed, treat the fall as one level less on the Falling table.

## <span id="movement-falling">Falling</span>

| Distance | Result |
| --- | --- |
| &gt; 3" | Suppressed; ends its turn if activating. |
| 3" – 6" | Suppressed; ends its turn if activating; suffers 1 automatic Lethality 1 wound, no saves. |
| ≥ 6" | Out of Action. |

<p class="text-small text-muted">Falling on another model: roll a D6 &mdash; on a 4+, that model suffers the same result as the faller.</p>
