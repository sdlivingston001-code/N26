| Action | Type | Effect |
|---|---|---|
| Treat Ally | Single | A Seriously Injured fighter within 1" immediately makes a Recovery test. |
| Repair | Single | A Seriously Damaged vehicle within 1" immediately makes a Recovery test. |
| Coup de Grace | Single | Against a Seriously Injured fighter within 1": both models roll a D6 and add Strength; if tied, or the attacker is higher, the target is taken Out of Action. |
| Sabotage | Single | Against a Seriously Damaged vehicle within 1": if the attacker passes an Intelligence check, the target is taken Out of Action. |
| Interact | Single | Interact with an object or terrain feature; effects vary. |
| Group Activation | Single | Select any number of Active fighters within 3" and make a Leadership check (stacking -1 for each additional fighter beyond the first). If passed, all chosen fighters activate immediately, one after another. |
